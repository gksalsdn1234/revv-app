## ⚖️ 라이선스 판정 (정밀 확인 완료 2026-07-18) — 중요

tkl-demo에는 두 가지 남의 IP가 들어있다. 판매 방식이 여기서 갈린다.

### 1. GPL-3.0 (홀로 이펙트 CSS)
- `app/vendor/pokemon-cards-css/css/` = simeydotme/pokemon-cards-css 원본, **GPL-3.0 카피레프트**. `app/layout.js`에서 실제 import되어 배포물에 포함됨.
- **✅ 안전한 방식 — 호스팅 서비스(SaaS)**: 내가 만들어서 **내가 호스팅**하고 샵은 브라우저로만 접속 → GPL의 "배포(distribution)"에 해당 안 됨 → 소스공개 의무 없음. (AGPL이면 걸리지만 이건 그냥 GPL이라 세이프.) **이 모델로 팔 것.**
- **❌ 위험한 방식 — 코드 판매/자체호스팅 납품**: 소스를 샵에 넘기면 GPL 발동 → 전체 소스를 GPL-3.0으로 공개해야 하고 샵이 재배포·재판매해도 못 막음. 프로프라이어터리 락다운 불가.
- **준수 조치**: 벤더 폴더에 `NOTICE.md` 추가 완료(저작자·라이선스 표기). 만약 코드를 배포하게 되면 GPL-3.0 전문(LICENSE)도 동봉해야 함.
- **완전 프로프라이어터리로 팔고 싶으면**: 홀로 CSS를 MIT/자체제작 이펙트로 교체(clean-room)하면 GPL 굴레 벗음. 지금은 불필요.

### 2. 포켓몬 IP (트레이드마크·카드 이미지) — GPL보다 오히려 큰 리스크
- 앱이 `pokemontcg.io`에서 실제 카드 데이터/이미지를 가져옴. 포켓몬 카드 이미지·명칭은 The Pokémon Company/닌텐도 IP.
- **안전 포지셔닝**: "우리는 **스토어프론트 소프트웨어**를 만든다. 재고·카드 이미지·판매 책임은 샵에 있다." 샵은 이미 실물 카드를 합법적으로 파는 사업자라 자기 재고 이미지 노출은 상대적으로 방어 가능(nominative use). 
- **하지 말 것**: 우리 브랜드를 "Pokémon"으로 마케팅, TPC 로고/공식 브랜딩 사용. 마케팅은 "TCG 카드샵 스토어프론트"로 (포켓몬 특정 X).
- 데모의 `crownvault`가 "익명화"된 이유가 이것 — IP 노출 최소화 인지하고 만든 흔적.

**결론: 호스팅 서비스로 팔면 GPL·IP 둘 다 세이프. 코드 자체를 파는 건 피할 것.**

## 실행 순서 (아웃리치)
1. Vercel 배포 → `/pitch` 프로덕션 URL 확보 (`pitch-checklist.md`의 Before Sending 체크)
2. `target-shops-template.csv`에 캐나다 카드샵 20곳 리서치 채우기 (인스타/구글맵으로 찾기)
3. `email-templates.md` Cold Email → 샵명·색상·이벤트만 채워 발송
4. 관심 보이면 24h 커스텀 데모(`shopConfig.js`에 slug 추가) → 계약
- 전환 팁: 카드샵은 지역 오프라인 사업자라 콜드 DM/이메일 전환율이 SNS보다 높음. 인스타 DM도 병행.
