## 1. 핵심 판단

₩100만은 "SNS 팔로워 수익"으로는 못 만든다 (TikTok/YT Shorts 수익화는 팔로워 1만+, 최소 2~3개월).
대신 아래 **2개 트랙을 동시에** 돌리면 4~8주 안에 현실적으로 도달 가능하다.

| 트랙 | 상품 | 단가 | ₩100만까지 필요 판매 | 현금화 속도 |
|---|---|---|---|---|
| A. 디지털 상품 | "BC 숨은 드라이브 코스 가이드" PDF/웹 | ₩12,000 (CAD $12) | 약 84건 | **빠름 (1~2주 내 첫 매출 가능)** |
| B. 앱 퍼널 | REVV 앱 유료 기능/IAP | 앱 가격 정책에 따름 | — | 중간 (출시 후) |
| C. 크리에이터 수익 | TikTok/Shorts 정산 | — | — | 느림 (2개월+, 보조 수단) |

**SNS는 "수익원"이 아니라 A·B로 트래픽을 보내는 "유통 채널"이다.**

## 2. 포지셔닝 — 북미 타겟 (확정)

- 페르소나: **"북미 숨은 드라이브 코스를 데이터로 찾아내는 개발자"**
- 앵글: 남들은 감으로 추천, 나는 커브 밀도·와인딩 점수 알고리즘으로 찾는다 (REVV 개발 스토리 자체가 콘텐츠)
- 언어: **영어 온리** (미국+캐나다, 시장 10배)
- 지역 확장: BC로 시작 → **PNW(워싱턴·오리건)로 프레임 확장** — "Pacific Northwest's best driving roads"가 BC보다 검색·해시태그 볼륨 훨씬 큼. 가이드 2탄은 PNW/캘리포니아
- 발행 시간: 북미 골든타임 — 평일 오후 6~9시 PST/EST 사이 (PST 오후 6시 = EST 9시로 양쪽 커버)
- 해시태그 확장: `#pnw #pacificnorthwest #pnwroads #usroadtrip #drivingroadsusa`
- 안전 언어 준수: "스릴/스피드" 금지 → "scenic", "winding", "hidden gem", "fun to drive"

## 3. 플랫폼 (1소스 3배포)

세로 영상 1개 → **TikTok + Instagram Reels + YouTube Shorts** 동시 업로드.
- 촬영: 대시캠/폰 거치 POV + REVV 앱 화면(G포스, 루트 지도) 오버레이
- 편집 템플릿 1개 고정: 훅(0~2초) → 루트 영상(3~20초) → 지도 리빌(끝) → CTA
- CTA: "전체 루트는 프로필 링크" → 링크트리 → 가이드 판매 페이지 + 앱 다운로드

## 4. 4주 실행 로드맵

### Week 1 — 세팅 + 상품 제작 (민우 작업 필요 항목 ★)
- ★ 계정 생성: TikTok / Instagram / YouTube (핸들 통일, 예: @revv.drives)
- ★ Gumroad(또는 Lemon Squeezy) 계정 + 결제 연결
- 가이드 v1 제작: 기존 route_service 데이터에서 상위 10개 루트 → 지도·거리·커브밀도·포토스팟 포함 PDF (Claude가 제작 가능)
- 콘텐츠 5개 촬영 (주말 드라이브 1회면 5~10개 클립 확보)

### Week 2 — 발행 시작
- 1일 1포스트 × 3플랫폼 (아래 14일 캘린더)
- 가이드 런칭 가격 $9 (첫 20명) → 이후 $12
- REVV 앱 TestFlight/사전예약 링크 병행 노출

### Week 3~4 — 반복 + 증폭
- 조회수 상위 포맷 2개로 압축, 주 5회 발행
- 로컬 커뮤니티 시딩: Reddit r/vancouver, r/VancouverIsland, r/cars 캐나다 스레드, 한인 카페 (자연스러운 후기 톤)
- 앱 출시 시점: "이 코스들 전부 앱에 있음" 전환 콘텐츠

### 목표 수치 (보수적)
- 4주 발행 40개 → 평균 조회 2천, 히트 1~2개 5만+
- 프로필 방문 3% → 링크 클릭 30% → 구매 전환 5% ≈ 30~50건 (₩36~60만)
- 히트 영상 1개 터지면 잔여분 커버. 미달 시 Week 5~6 연장 + 가이드 2탄(로키/앨버타).

## 4.5 자동화 파이프라인 (민우 손 = 주 30분)

"알아서 올라가는" 구조는 봇이 아니라 스케줄러로 만든다 (봇 포스팅은 계정 밴 리스크 → 퍼널 전멸).

```
[주말 드라이브 1회: 클립 촬영]
        ↓
[Claude: 대본·캡션·해시태그·발행시간 배치 생성 (주 단위)]
        ↓
[Metricool 무료 플랜: TikTok/IG/YT 연결 → 주 1회 배치 업로드·예약]
        ↓
[매일 자동 발행 — 3플랫폼 동시]
```

- **툴: Metricool** (무료 플랜으로 3플랫폼 연결+예약 가능, Buffer 무료는 채널 제한 빡빡함)
- 1회성 세팅 (민우, 약 30분): 계정 3개 생성 → Metricool 연결
- 반복 루틴: 촬영(주말) → Claude가 편집 지시서+캡션 배치 전달 → 민우 주 1회 예약 걸기 → 끝
- Claude 정기 지원: 주 1회 성과 리뷰(조회수 상위 포맷 분석) + 다음 주 배치 생성 — 스케줄 태스크로 자동화 가능
